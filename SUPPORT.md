# Support

Browser-Agent is under active development and is not yet a supported production browser.

- **Bug reports:** open a GitHub issue using the Bug Report template.
- **Feature requests:** open a GitHub issue using the Feature Request template.
- **Usage questions:** use GitHub Discussions if enabled; otherwise open a clearly labelled question
  issue.
- **Security vulnerabilities:** follow `SECURITY.md`; do not post them publicly.
- **Build failures:** include the exact commit, OS version, architecture, toolchain versions,
  command, and redacted output.

Please do not include credentials, cookies, private URLs, unredacted logs, model files, or personal
browsing data.
