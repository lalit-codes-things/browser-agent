## Status model

| Spec status | Meaning | Verification status | Meaning |
|---|---|---|---|
| LOCKED | Explicitly fixed by Revision 2. | NOT-VERIFIABLE-YET | Gate is real but its evidence cannot exist until the owner phase runs. |
| TUNABLE | Existence is locked; numeric/value parameter may be tuned within the specified process/boundary. | SCHEDULED | Test/evidence is defined but not yet evidenced in the catalog source. |
| PROVISIONAL | Explicitly provisional pending benchmark/evidence. | PARTIAL | Some evidence exists, but the verification set is incomplete. |
| MEASUREMENT-ADR | Outcome is intentionally determined by evidence and recorded as an ADR. | VERIFIED | Evidence is present and accepted. |
| PROPOSED | Source explicitly labels the scope as proposed expansion. | FAILED-BLOCKING | Verification failed and blocks release. |
| SUPERSEDED | Replaced by a later explicit constraint. | | |
